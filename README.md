# TravelPlannerAgent

Steps to run this project

1. uv init 
2. uv venv
3. activate env 
4. uv add -r requirements.txt
5. uv run streamlit run app.py

Requirements:

1. GOOGLE_API_KEY
2. WEATHER_API_KEY
3. OLLAMA_API_KEY
4. LANGSMITH_API_KEY
